School Educational System - QA Capstone Project

Deliverables phase -1
Project Overview:

This project focuses on testing a School Educational System which includes student registration,
login, course search, enrollment, payment, and dashboard functionalities.

SDLC Phases

Requirement Analysis, Planning, Design, Development, Testing.

Functional Modules

1. Student Registration
2.Login & Logout
3. Course Search
4 Course Details
5 Admission Cart
6 Fee Payment
7 Enrollment Confirmation Order confirmation
8 Student Dashboard

Non-Functional Requirements

View enrolled courses
Performance: Pages should load within 2-3 seconds and support multiple users. Usability: Simple
UI, easy navigation, clear error messages. Reliability: System should not crash and data should be
saved correctly.
